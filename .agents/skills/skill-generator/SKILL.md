# Generador y Optimizado de Especificaciones (Spec-Driven Development)

Esta habilidad guía al agente en la revisión crítica de una especificación existente para redactar una versión nueva y optimizada.

## Cuándo usar esta skill
- Cuando el usuario solicita actualizar una especificación técnica debido a cambios de requisitos.
- Cuando se detectan cuellos de botella, deuda técnica o carencias en una spec actual.

## Pasos para la ejecución

1. **Lectura y Análisis:**
   - Analiza la especificación actual proporcionada por el usuario.
   - Identifica ambigüedades, asunciones obsoletas, carencias de seguridad o problemas de rendimiento.

2. **Propuesta de Mejoras:**
   - Lista brevemente los puntos clave que se van a mejorar respecto a la versión anterior (arquitectura, modularidad, tipado, flujos, etc.).

3. **Generación de la Nueva Spec:**
   - Redacta la nueva especificación estructurada y lista para usar en flujos de Spec-Driven Development.
   - Asegúrate de incluir secciones claras: objetivos, alcance, arquitectura/diseño técnico, modelos de datos, flujos de trabajo y criterios de aceptación.
